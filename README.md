# Labelator

Design labels, fill them from Excel, and download print-ready PDFs.

**Live:** [https://agatonovic.github.io/liberator/](https://agatonovic.github.io/liberator/)

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Data stays in the browser (IndexedDB).

## GitHub Pages

Pushes to `main` build a static export and deploy to GitHub Pages. The site is served under `/liberator`.
